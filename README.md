# Doctor Tracker Frontend
Responsive, animated and accessible administration UI for Doctor Tracker, planned with Next.js App Router and React. The reviewed main page currently remains the default Next.js starter; feature implementation and test execution are not verified.
## Local setup target
Use the package manager declared in package.json, copy .env.example to .env.local, set the local API URL, install dependencies and run the dev script. Implement features according to docs/01-srs.md and docs/07-ui-ux-motion.md.
## Engineering references
SRS: docs/01-srs.md; architecture: docs/02-architecture.md; UI motion: docs/07-ui-ux-motion.md; tests: docs/08-test-and-quality-plan.md; status: docs/13-github-workflow-and-status.md.
Any NEXT_PUBLIC variable is browser-visible and must not contain a secret. Use synthetic data in screenshots. Follow CONTRIBUTING.md and SECURITY.md.

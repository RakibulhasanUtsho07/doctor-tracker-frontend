# Privacy and Data Governance
Collect only data necessary to track doctors and patients. Confirm patient fields and condition vocabulary before implementation. Restrict data views to administrators and return only fields needed by each screen.
Never use real patient data in tests, screenshots, issues or logs. Keep sensitive values out of URLs, analytics and client errors. Define retention, deletion semantics and access to backups. Encrypt backups where supported.
This engineering baseline is not legal-compliance certification. Review applicable Bangladesh law, hosting terms, organizational policy and contract before using real patient data.
